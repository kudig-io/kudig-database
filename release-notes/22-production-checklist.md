## 质量检查清单

### 主视频

```
□ 画面清晰度 ≥ 1080p
□ 字幕无错别字
□ 语速适中 (不过快/不过慢)
□ 背景色统一 (#0A1628 深蓝渐变)
□ logo 出现在指定位置
□ 总时长 14-16 分钟
□ 无明显口型不同步
□ BGM 音量不抢人声
```

### 短视频

```
□ 竖版 1080x1920 (抖音/视频号) 或 横版 1920x1080 (B站)
□ 前 3 秒有强 Hook
□ 字幕清晰可读
□ 时长 30-60 秒
□ 结尾有 CTA (关注/Star/扫码)
```

### 海报

```
□ 主标题清晰可读
□ 核心数据突出
□ 品牌色一致
□ 适合社交媒体分享尺寸
□ 有二维码或链接
```

## 常见问题

### Q: 数字人口型不同步怎么办?

```
A: 
1. 检查语速设置, 中文建议 3.5-4.0 字/秒
2. 将长句拆分为短句 (每句不超过 30 字)
3. 在逗号/句号处添加停顿标记
4. 如果平台支持, 调整 "lip sync" 灵敏度
```

### B: 生成的视频有杂音怎么办?

```
A:
1. 检查原始音频是否有底噪
2. 用 Adobe Podcast (免费) 降噪: https://podcast.adobe.com/enhance
3. 后期用剪映/Premiere 的降噪功能
```

### C: 数字人表情太僵硬怎么办?

```
A:
1. 在台词中加入情绪标记 (平台通常支持)
2. 将长段落拆分为多个短场景
3. 在关键句后添加停顿, 让数字人"呼吸"
4. 考虑换一个更自然的数字人形象
```
