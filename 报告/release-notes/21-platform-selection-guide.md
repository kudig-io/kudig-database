## 一、30 秒决策树

```
你的核心需求是什么?
│
├─ "我要最好的效果, 预算不是问题"
│   └─ → HeyGen ($89/月) — 数字人质量最高, 中文支持好

├─ "我要中文效果最好, 国内访问稳定"
```

## 二、各平台详细对比

### HeyGen (推荐首选)

```
官网: https://heygen.com
价格: Creator $89/月 (15 分钟/月) | Business $288/月 (60 分钟/月)
数字人质量: ★★★★★
中文支持: ★★★★☆ (有中文数字人, 口型同步好)
上手难度: ★★☆☆☆ (很简单)
国内访问: 需要 VPN

优势:
  - 数字人最自然, 口型同步准确
  - 支持上传 PPT 作为背景
  - 支持自定义数字人形象 (上传照片训练)
  - 有 API 可批量生成
  - 支持 4K 输出

劣势:
  - 需要 VPN
  - 免费额度少 (1 分钟)
  - 中文数字人选择有限

适合: 主视频 (15 分钟) + 关键短视频
```

### 腾讯智影 (中文首选)

```
官网: https://zenvideo.qq.com
价格: 个人版 ¥299/月 | 企业版 ¥999/月
数字人质量: ★★★★☆
中文支持: ★★★★★ (原生中文, 最自然)
上手难度: ★★☆☆☆
国内访问: ✅ 直连

优势:
  - 中文口型同步最准确
  - 数字人形象选择多 (几十个)
  - 支持上传 PPT/图片作为背景
  - 国内服务器, 速度快
  - 有直播数字人功能

劣势:
  - 英文效果一般
  - 高级功能需企业版
  - 输出分辨率最高 1080p

适合: 中文主视频 + 国内传播短视频
```

### 剪映数字人 (短视频首选)

```
官网: https://www.capcut.cn
价格: 免费 (有水印) | 会员 ¥99/月 (无水印)
数字人质量: ★★★☆☆
中文支持: ★★★★★
上手难度: ★☆☆☆☆ (最简单)
国内访问: ✅

优势:
  - 完全免费 (有水印)
  - 和剪辑无缝集成

劣势:
  - 数字人选择有限
  - 不支持自定义形象
  - 长视频效果一般

适合: 短视频切片 (30-60 秒) + 快速原型
```

## 三、推荐制作方案

### 方案 A: 快速出活 (今天开始)

```
主视频 (15 分钟): HeyGen 或 腾讯智影
短视频切片 (6 个): 剪映数字人
预告片 (60 秒): HeyGen (效果最好)
总预算: ~¥500-800

步骤:
  1. 注册 HeyGen 或腾讯智影 (10 分钟)
  2. 选择数字人形象 (10 分钟)
  3. 逐段输入台词 (19-digital-human-video.md 中的逐字稿)
  4. 选择背景 (深蓝色渐变 #0A1628)
  5. 生成预览 → 调整 → 导出
  6. 用剪映剪辑短视频切片
```

### 方案 B: 最高质量 (1-2 周)

```
主视频 (15 分钟): HeyGen Business (4K)
预告片 (60 秒): HeyGen + Runway AI 视频混合
短视频切片 (6 个): 腾讯智影 (中文最佳)
品牌视觉: Midjourney 生成海报 + Figma 排版
总预算: ~¥2000-3000

步骤:
  1. HeyGen 注册 Business 账号
  2. 上传品牌素材 (logo/配色/字体)
  3. 逐段制作主视频, 每段单独导出
  4. 腾讯智影制作中文优化版短视频
  5. Runway 生成 AI 辅助画面 (终端截图/架构图动画)
  6. 用 DaVinci Resolve 或 Premiere 合成
  7. 添加字幕/BGM/转场
```

## 四、立即开工: HeyGen 操作步骤

### Step 1: 注册 (5 分钟)

```
1. 打开 https://heygen.com (需 VPN)
2. 点击 "Get Started" → 用 Google/邮箱注册
3. 选择 Creator Plan ($89/月) 或先用免费试用
4. 完成支付
```

### Step 2: 创建视频 (10 分钟)

```
1. 点击 "Create Video" → "AI Avatar"
2. 选择数字人:
   - 推荐: "Josh" (男性, 商务休闲) 或 "Amelia" (女性, 专业)
   - 语言: 选择 "Chinese (Mandarin)"
3. 设置画布: 16:9 (1920x1080)
```

### Step 3: 输入台词

```
将 19-digital-human-video.md 中的逐字稿逐段粘贴:

段落 1 (开场 Hook):
  粘贴 "你是一个 [[实体/kubernetes.md|k8s]] 运维工程师..." 全文
  点击 "Generate Preview"

段落 2 (产品介绍):
  新建 Scene → 粘贴 "kudig-database 是什么?..."
  点击 "Generate Preview"

重复以上步骤, 共 5 个 Scene
```

### Step 4: 设置背景

```
1. 点击 "Background" → "Color"
2. 输入渐变色:
   - 起始: #0A1628 (深蓝)
   - 结束: #1A2A4A (浅蓝)
3. 或上传品牌背景图
```

### Step 5: 导出

```
1. 点击 "Submit" → 等待渲染 (约 5-10 分钟)
2. 导出为 MP4 (1080p)
3. 下载到本地
```

## 五、立即开工: 腾讯智影操作步骤

### Step 1: 注册 (3 分钟)

```
1. 打开 https://zenvideo.qq.com
2. 用微信/QQ 登录
3. 选择个人版或企业版
4. 完成支付 (支持微信/支付宝)
```

### Step 2: 创建视频

```
1. 点击 "数字人播报" → "新建项目"
2. 选择数字人:
   - 推荐: "小智" (男性, 技术感) 或 "小影" (女性, 亲切)
   - 语速: 中等偏快
3. 设置分辨率: 1920x1080
```

### Step 3: 输入台词

```
1. 在台词输入框中粘贴逐字稿
2. 每段不超过 500 字 (超过自动分段)
3. 点击 "预览" 查看效果
4. 调整语速和停顿
```

### Step 4: 设置背景

```
1. 点击 "背景" → "纯色"
2. 输入 #0A1628
3. 或上传品牌背景图
```

### Step 5: 导出

```
1. 点击 "生成视频"
2. 等待渲染 (约 3-5 分钟)
3. 下载 MP4
```

## 六、短视频切片: 剪映操作步骤

### Step 1: 打开剪映

```
1. 下载剪映桌面版: https://www.capcut.cn
2. 登录账号
3. 点击 "图文成片" 或 "数字人"
```

### Step 2: 选择模板

```
1. 搜索 "知识口播" 或 "技术讲解"
2. 选择一个深色背景模板
3. 替换文字为短视频旁白 (20-complete-script-book.md 中的切片旁白)
```

### Step 3: 生成并导出

```
1. 点击 "生成"
2. 预览效果
3. 调整字幕样式
4. 导出为 1080x1920 (竖版) 或 1920x1080 (横版)
```
