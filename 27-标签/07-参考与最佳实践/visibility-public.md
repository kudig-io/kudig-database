## 公开可见性标签指南

### 内容分级

| 级别 | 说明 | 示例 |
|---|---|---|
| 公开 | 可对外分享 | 博客、演讲、开源 |
| 内部 | 仅团队可见 | 架构文档、运维手册 |
| 机密 | 严格限制 | 凭证、客户数据 |

### 公开内容检查清单

1. **敏感信息**：无密码、Token、内部 IP
2. **客户数据**：无客户名称、业务数据
3. **内部工具**：无内部系统截图
4. **合规审查**：符合公司发布政策

## 面试要点

1. **Q：技术内容发布的注意事项？**
   A：脱敏处理、合规审查、版权确认、技术准确性、品牌一致性。

2. **Q：如何平衡分享与保密？**
   A：明确分级、脱敏处理、审批流程、定期审查。

3. **Q：技术影响力的建设？**
   A：持续输出、高质量内容、多渠道分发、社区互动、个人品牌。
