## 三、技术社区文案 (掘金/SegmentFault/知乎)

### 标题
**我们把 3,346 篇 K8s 生产运维知识做成了 AI 智能体的语料库**

### 正文

大家好, 我们做了一件事: 把 [[entities/kubernetes.md|kubernetes]] 生产运维的完整知识体系, 结构化成了 AI 智能体可以直接使用的语料库。

**它是什么?**

kudig-database 是一个面向 K8s 生产运维的知识库, 包含:
- 40 个知识域 (控制平面/网络/存储/安全/可观测/AI基础设施...)
- 97 个行业架构场景 (电商/金融/医疗/IoT/自动驾驶...)
- 218 个 CNCF 项目文档
- 18 个可执行的问题排查 SOP
- 13 张速查卡
- 208 篇术语词典

**它能做什么?**

接入 RAG 后, 智能体可以:
1. 深度研究某个技术领域 (输出 30 分钟以上的系统性知识)
2. 排查线上问题 (直接调用诊断脚本, 输出结构化步骤)
3. 解读 kubectl 输出 (精准匹配 23 种诊断模式)
4. 设计行业架构方案 (97 个场景, 含完整 YAML 配置)
5. 速查命令和术语 (秒级返回)
6. 规划学习路径 (2 套 28 天培训体系)

**怎么用?**

导入 NotebookLM / RAG 系统 / Agent 框架即可。我们提供了:
- 4 套 RAG Profile 配置 (SRE Agent / 学习助手 / 全量语料 / NotebookLM)
- 标准化 YAML front matter (98% 覆盖)
- RAG 分块策略指南
- QA 对语料 (982 组)

欢迎试用和反馈。
