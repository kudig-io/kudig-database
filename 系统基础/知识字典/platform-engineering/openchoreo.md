# OpenChoreo 开发者平台（OpenChoreo）

## 概述

OpenChoreo 是 WSO2 开源的内部开发者平台（IDP），基于 Kubernetes 构建，提供应用全生命周期管理、CI/CD、可观测性和 API 管理的统一平台，是 Backstage + Argo 的开箱即用整合。

## 核心概念/原理

- **IDP 平台**：内部开发者平台的一站式方案
- **K8s 原生**：基于 Kubernetes 的应用管理
- **全生命周期**：从代码到生产的完整流程
- **WSO2 开源**：基于 WSO2 Choreo 商业平台的开源核心

## 关键机制或特性

- 组件模型（Component）定义应用和服务
- 内置 CI/CD Pipeline
- API 管理和网关
- 可观测性集成（Metrics/Logs/Traces）
- 环境管理（Dev/Staging/Prod）
- 多租户组织管理
- Git 驱动的配置管理

## 使用场景与最佳实践

- 企业级内部开发者平台
- 应用全生命周期管理
- API 管理和微服务治理
- 多团队协作的开发平台
- Backstage + Argo 的集成替代
