# 阿里云

> 阿里云容器服务的三条知识轨：**专有云（Apsara Stack）运维主干**、**公有云 ACK 托管服务** 与 **分布式云 ACK One（多集群/混合云）**。

阿里云文档按交付形态分为三轨。远程顾问/SRE 场景以专有云运维主干为重点；通用云原生团队以公有云 ACK 为主；多集群、混合云与容灾治理走分布式云 ACK One。
