# calico v3.30 Release Notes

Source: [v3.30.7](https://github.com/projectcalico/calico/releases/tag/v3.30.7)

Release notes can be found [on GitHub](https://github.com/projectcalico/calico/blob/release-v3.30/release-notes/v3.30.7-release-notes.md)

Attached to this release are the following artifacts:

- `release-v3.30.7.tgz`: container images, binaries, and kubernetes manifests.
- `calico-windows-v3.30.7.zip`: Calico for Windows.
- `tigera-operator-v3.30.7.tgz`: Calico Helm v3 chart.
- `ocp.tgz`: Manifest bundle for OpenShift.
