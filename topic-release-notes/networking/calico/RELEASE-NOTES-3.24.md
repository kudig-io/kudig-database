# calico v3.24 Release Notes

Source: [v3.24.6](https://github.com/projectcalico/calico/releases/tag/v3.24.6)


Release notes can be found [on GitHub](https://github.com/projectcalico/calico/blob/v3.24.6/calico/_includes/release-notes/v3.24.6-release-notes.md)

Attached to this release are the following artifacts:

- `release-v3.24.6.tgz`: container images, binaries, and kubernetes manifests.
- `calico-windows-v3.24.6.zip`: Calico for Windows.
- `tigera-operator-v3.24.6.tgz`: Calico Helm v3 chart.
- ocp.tgz: Manifest bundle for OpenShift.
