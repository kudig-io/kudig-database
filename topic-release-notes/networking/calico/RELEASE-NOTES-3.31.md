# calico v3.31 Release Notes

Source: [v3.31.4](https://github.com/projectcalico/calico/releases/tag/v3.31.4)

Release notes can be found [on GitHub](https://github.com/projectcalico/calico/blob/release-v3.31/release-notes/v3.31.4-release-notes.md)

- `calico-windows-v3.31.4.zip`: Calico for Windows.
- `tigera-operator-v3.31.4.tgz`: Calico Helm v3 chart.
- ocp.tgz: Manifest bundle for OpenShift.
