# CNCF 毕业项目 Graduated

## 核心毕业项目

| 项目 | 类别 | 核心能力 |
|------|------|----------|
| Kubernetes | 编排 | 容器编排与调度 |
| Prometheus | 可观测性 | 指标采集与告警 |
| Envoy | 网络 | L4/L7 代理与 Service Mesh |
| CoreDNS | 网络 | 服务发现 DNS |
| etcd | 存储 | 分布式 KV 存储 |
| Helm | 应用定义 | 包管理与部署 |

| Argo | 持续交付 | GitOps/工作流 |
| Cilium | 网络 | eBPF 网络与安全 |
| Istio | 网络 | Service Mesh 控制平面 |
