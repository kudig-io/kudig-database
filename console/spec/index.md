## 2. 与现有实现的关系

Console v1（已建）提供：总览分层谱、结构图（S0–S7 带 / 库图 / 层级谱）、图表库（2,277 张 Mermaid 本地渲染）、阅读页。

本设计（v2）**不推翻 v1，而是补上"语料外层的结构"**：

| 现有 | 本设计新增 | 变化 |
|---|---|---|
| 分层谱（页 × 层） | 构成剖面 | 保留为口径之一 |
| 结构带（S0–S7） | 拆解树 | 从"页的位置"细化到"页的段落" |
| 图表库 | — | 不变 |
| 阅读页 | 证据页 | 降级：不承担导航 |
| — | 一致性热力、对比矩阵、关系邻域、演化时间线 | 新增 |

## 3. 一句话原则（贯穿所有文档）

1. **无锚点不成图**：结论必须能落到 `页 + 行号`。
2. **空即空**：语料没写就显示"未成节"，不借其他页补。
3. **一色一义**：蓝 = 已对齐，琥珀 = 缺口，没有第三种语义色。
4. **结构是产品，阅读是证据**。
