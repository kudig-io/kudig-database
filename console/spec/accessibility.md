# Console 交互与无障碍规范

> 结构视图的信息密度天然高于列表，交互规范的核心是**不让人迷路**：任何时刻用户都应该知道"我在哪个视图、我是从哪个元素来的、回去按哪里"。

## 1. 交互模型：结构元素 → 证据抽屉 → 原文

```
[结构视图]  ──点击元素──▶  [证据抽屉（右侧，不跳页）]  ──点击"定位原文"──▶  [阅读页 · 高亮该行]
     ▲                            │
     └────── Esc / 关闭 ──────────┘
```

### 1.1 规则

1. **同页抽屉**：点击结构元素**不跳页**，右侧滑出抽屉（宽 360px，≤1180px 时变为底部面板），保持视图上下文。
2. **抽屉内容固定三段**：`结论`（一句话）→ `证据`（页 + 小节 + 行号）→ `动作`（定位原文 / 复制链接）。
3. **定位原文**才离开结构视图；阅读页顶部出现"← 返回 [上一结构视图]（保留筛选）"。
4. **URL 可分享**：抽屉打开时地址栏追加 `?focus=<结构元素id>`，刷新后还原同一抽屉。

### 1.2 焦点管理

| 动作 | 焦点去向 |
|---|---|
| 打开抽屉 | 抽屉标题（`role="dialog"`，`aria-labelledby`） |
| 关闭抽屉 | 触发它的结构元素 |
| 进入阅读页 | 正文首个标题 |
| 从阅读页返回 | 原结构元素（恢复滚动位置） |

## 2. 键盘模型

| 键 | 作用 | 范围 |
|---|---|---|
| `1`–`6` | 切换六个结构视图（构成 / 拆解 / 热力 / 矩阵 / 邻域 / 时间线） | 全局，输入框聚焦时禁用 |
| `⌘K` / `/` | 打开命令面板（搜结构元素或页） | 全局 |
| `↑ ↓ ← →` | 在矩阵/热力格之间移动 | 格状视图 |
| `Enter` | 打开当前元素证据 | 格状视图 |
| `Esc` | 关闭抽屉 → 关闭面板 → 返回上一视图（逐层） | 全局 |
| `Tab` | 按视觉顺序走：侧栏 → 主视图 → 抽屉 | 全局 |

### 2.1 格状视图的 roving tabindex

矩阵与热力使用单一 tab 停靠点（当前格），方向键在格间移动，`Enter` 打开。**禁止**每个格都进 tab 序列（4 列 × 86 行 = 344 个停靠点）。

## 3. 无障碍

### 3.1 图形等价

| 视图 | 等价形式 |
|---|---|
| 构成剖面 | `<table>`：分区 / tier / 页数 |
| 拆解树 | 嵌套 `<ul>` + `aria-level` |
| 一致性热力 | `<table>`：行 = 域，列 = 维度，单元格文字 = 专节/提及/未成节 |
| 对比矩阵 | `<table>`：单元格 = 摘要 + 链接 |
| 关系邻域 | 邻接列表：`中心 → 邻居（入链数）` |
| 演化时间线 | `<table>`：月份 / 0–2 层 / 3–5 层 / 6–7 层 |

切换按钮固定在每个面板头部：`图 / 表`，默认跟随 `prefers-reduced-motion` 与用户上次选择。

### 3.2 颜色之外的编码

- 三态格：蓝实 / 蓝浅 / 琥珀虚线——**同时**用文字（`专节` `提及` `未成节`）与边框样式（实/浅/虚）编码；
- 关系邻域：节点半径映射入链，**同时**在节点文字后给出数字；
- 构成剖面：段宽映射页数，**同时**在段内标数字（若段宽 ≥ 48px，否则悬停与表格视图给出）。

### 3.3 对比度底线

| 元素 | 最低对比度 |
|---|---|
| 正文 | 4.5:1 |
| 大号数字/标题 | 3:1 |
| 琥珀文字（`#7D4A05`）在琥珀浅底（`#FCF5EA`） | 6.79:1（已达标） |
| 格内白字在蓝底（`#1E40AF`） | 7.4:1（已达标） |

### 3.4 动效

- 结构视图切换**不做**整页过渡动画；只有抽屉 200ms 位移。
- `prefers-reduced-motion: reduce` 时：关闭所有过渡、时间线不做入场动画、邻域图不做半径插值。

## 4. 空态、错误态与加载态

| 状态 | 表现 | 文案要求 |
|---|---|---|
| 无数据（视图级） | 虚线框 + 说明 + "切换视图" | 说明是"该筛选无结果"还是"数据未生成" |
| 证据缺失 | 元素仍可点，抽屉显示"该结论缺少锚点" | 这是缺陷，需上报，不得静默隐藏 |
| 加载中 | 骨架屏（保持布局，不跳动） | 超过 2s 显示"正在抽取第 N 页" |
| 部分失败 | 该元素加小标记，其余正常 | 全量失败才整页错误 |

## 5. 响应式

| 断点 | 布局变化 |
|---|---|
| ≥1180px | 侧栏 300 + 主区 + 抽屉 360 三栏 |
| 900–1180px | 抽屉改为覆盖层；矩阵列可横滚 |
| 760–900px | 侧栏变抽屉；视图切换改为两行 |
| ≤760px | 单列；矩阵默认改为"行 = 实体，列折叠为可展开卡片"；热力格最小 28px |
| ≤420px | 视图标签用短名（构成 / 拆解 / 热力 / 矩阵 / 邻域 / 时间） |

移动端原则：**优先保证"能判断"，其次保证"能看完"**——矩阵在手机上只显示摘要首行，点开看全格。

## 6. 性能预算

| 指标 | 预算 | 手段 |
|---|---|---|
| 首屏（结构与字体） | < 2s @ 4G | 只加载当前视图所需 JSON |
| 视图切换 | < 500ms | 预取相邻视图索引；矩阵/热力纯 CSS 渲染 |
| 抽屉打开 | < 300ms | 证据与索引一并加载（`triples.json` 按域切片） |
| 内存 | < 200MB | 邻域图节点上限 60；矩阵不渲染 DOM 之外的格 |

---

## 7. 可信度提示（必须）

结构视图是**抽取结果**，不是原文本身。每个视图下方固定一行小字：

```
抽取规则见 console/spec/data-contract.md · 共 N 条结论 · 最近重建 2026-11-10
```

点击进入数据契约，让读者随时能检验"这个结论是怎么来的"。
