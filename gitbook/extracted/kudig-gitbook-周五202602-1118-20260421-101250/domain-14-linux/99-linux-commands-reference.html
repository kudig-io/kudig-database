Linux 命令大全参考

概述

本文档提供了 Linux 系统完整的命令参考，包括命令名称、命令用途、功能清单、注意事项以及安全生产风险提示。

系统信息命令

uname

  • 命令用途: 显示系统信息
  • 功能清单:
    • 显示内核名称 (-s)
    • 显示内核版本 (-r)
    • 显示硬件架构 (-m)
    • 显示所有信息 (-a)
  • 注意事项:
    • 需要基本系统访问权限
    • 不涉及敏感信息
  • 安全生产风险:
    • 输出可能暴露系统版本信息
    • 避免在不安全环境中显示详细系统信息

lsb_release

  • 命令用途: 显示发行版信息
  • 功能清单:
    • 显示发行版描述
    • 显示发行版代号
    • 显示版本号
  • 注意事项:
    • 某些发行版可能不预装此命令
    • 需要适当权限访问系统文件
  • 安全生产风险:
    • 可能暴露系统版本信息给攻击者
    • 有助于针对特定漏洞进行攻击

uptime

  • 命令用途: 显示系统运行时间
  • 功能清单:
    • 显示系统运行时长
    • 显示当前时间
    • 显示系统负载
  • 注意事项:
    • 负载信息反映系统压力
    • 高负载可能表示性能问题
  • 安全生产风险:
    • 无直接安全风险
    • 负载信息可用于系统分析

hostname

  • 命令用途: 显示或设置系统主机名
  • 功能清单:
    • 显示当前主机名
    • 临时修改主机名
    • 永久修改主机名
  • 注意事项:
    • 临时修改重启后失效
    • 永久修改需编辑配置文件
  • 安全生产风险:
    • 主机名变更可能影响网络服务
    • 确保 DNS 记录同步更新

whoami/id

  • 命令用途: 显示用户身份信息
  • 功能清单:
    • 显示当前用户名
    • 显示用户ID和组ID
    • 显示所属组信息
  • 注意事项:
    • 用于权限验证
    • 检查当前执行权限
  • 安全生产风险:
    • 无直接安全风险
    • 用于权限审计

w/who

  • 命令用途: 显示登录用户信息
  • 功能清单:
    • 显示当前登录用户
    • 显示用户登录时间
    • 显示用户活动状态
  • 注意事项:
    • w 命令显示更详细信息
    • who 命令显示基本信息
  • 安全生产风险:
    • 暴露在线用户信息
    • 可用于安全审计

last

  • 命令用途: 显示用户登录历史
  • 功能清单:
    • 显示最近登录记录
    • 显示登录时间和来源
    • 显示系统重启记录
  • 注意事项:
    • 读取 /var/log/wtmp 文件
    • 用于安全审计
  • 安全生产风险:
    • 暴露登录历史信息
    • 可识别异常登录行为

date

  • 命令用途: 显示或设置系统日期时间
  • 功能清单:
    • 显示当前系统时间
    • 格式化时间输出
    • 设置系统时间（需要root权限）
  • 注意事项:
    • 时间同步对系统很重要
    • 建议使用 NTP 服务同步时间
  • 安全生产风险:
    • 时间修改可能影响日志时间戳
    • 可能影响基于时间的安全策略

cal

  • 命令用途: 显示日历
  • 功能清单:
    • 显示当前月日历
    • 显示指定月份日历
    • 显示全年日历
  • 注意事项:
    • 主要用于查看日期信息
    • 简单实用的日期工具
  • 安全生产风险:
    • 无显著安全风险
    • 仅用于日期查询

timedatectl

  • 命令用途: 控制系统时间和日期
  • 功能清单:
    • 显示时间状态信息
    • 设置系统时间
    • 配置时区
    • 管理 NTP 同步
  • 注意事项:
    • 现代 Linux 系统推荐使用
    • 替代传统的 date 命令
  • 安全生产风险:
    • 时间配置错误可能影响系统日志
    • 确保时区设置正确

hwclock

  • 命令用途: 硬件时钟管理
  • 功能清单:
    • 显示硬件时钟时间
    • 同步系统时间到硬件时钟
    • 同步硬件时钟到系统时间
  • 注意事项:
    • 系统启动时使用硬件时钟
    • 需要 root 权限操作
  • 安全生产风险:
    • 硬件时钟错误影响系统启动
    • 时间同步问题可能影响服务

文件系统命令

ls

  • 命令用途: 列出目录内容
  • 功能清单:
    • 显示文件和目录列表
    • 显示权限信息 (-l)
    • 显示隐藏文件 (-a)
    • 递归显示 (-R)
  • 注意事项:
    • 使用 -h 参数人性化显示文件大小
    • 避免在大目录中使用递归选项
  • 安全生产风险:
    • 可能暴露目录结构和文件名
    • 某些文件名可能包含敏感信息

cp

  • 命令用途: 复制文件和目录
  • 功能清单:
    • 复制文件
    • 复制目录 (-r)
    • 保持属性 (-p)
    • 交互式复制 (-i)
  • 注意事项:
    • 复制大文件时注意磁盘空间
    • 使用 -i 参数避免意外覆盖
  • 安全生产风险:
    • 误复制敏感文件到不安全位置
    • 可能导致权限问题

mv

  • 命令用途: 移动或重命名文件
  • 功能清单:
    • 移动文件
    • 重命名文件
    • 交互式移动 (-i)
  • 注意事项:
    • 重命名操作会覆盖同名文件
    • 跨文件系统移动相当于复制后删除
  • 安全生产风险:
    • 误移动或重命名关键系统文件
    • 可能破坏系统功能

rm

  • 命令用途: 删除文件和目录
  • 功能清单:
    • 删除文件
    • 递归删除目录 (-r)
    • 交互式删除 (-i)
    • 强制删除 (-f)
  • 注意事项:
    • 删除操作无法恢复
    • 使用 -i 参数增加安全性
    • 避免使用 rm -rf /
  • 安全生产风险:
    • 误删除系统关键文件可能导致系统崩溃
    • 使用通配符时格外小心
    • -f 参数会强制删除，跳过确认

find

  • 命令用途: 搜索文件和目录
  • 功能清单:
    • 按名称搜索
    • 按类型搜索
    • 按大小搜索
    • 按修改时间搜索
    • 执行操作 (-exec)
  • 注意事项:
    • 在大目录中搜索可能消耗大量资源
    • 使用适当的搜索条件缩小范围
  • 安全生产风险:
    • -exec 参数可能执行危险操作
    • 搜索结果可能暴露敏感文件位置

mkdir

  • 命令用途: 创建目录
  • 功能清单:
    • 创建单个目录
    • 递归创建多层目录 (-p)
    • 设置目录权限 (-m)
  • 注意事项:
    • 使用 -p 参数避免父目录不存在错误
    • 合理设置目录权限
  • 安全生产风险:
    • 创建敏感路径可能暴露系统结构
    • 权限设置不当可能造成安全漏洞

rmdir

  • 命令用途: 删除空目录
  • 功能清单:
    • 删除空目录
    • 递归删除空目录树 (-p)
  • 注意事项:
    • 只能删除空目录
    • 非空目录需使用 rm -r
  • 安全生产风险:
    • 误删重要系统目录
    • 影响目录结构完整性

touch

  • 命令用途: 创建空文件或更新文件时间戳
  • 功能清单:
    • 创建新文件
    • 更新文件访问时间
    • 更新文件修改时间
  • 注意事项:
    • 不会覆盖已有文件内容
    • 可用于测试文件权限
  • 安全生产风险:
    • 在敏感目录创建文件可能暴露信息
    • 时间戳修改可能影响日志分析

ln

  • 命令用途: 创建链接
  • 功能清单:
    • 创建硬链接
    • 创建软链接 (-s)
  • 注意事项:
    • 硬链接不能跨文件系统
    • 软链接可以指向目录
  • 安全生产风险:
    • 循环链接可能导致系统问题
    • 恶意链接可能绕过安全控制

stat

  • 命令用途: 显示文件详细状态信息
  • 功能清单:
    • 显示文件权限和所有权

    • 显示文件大小和inode信息
  • 注意事项:
    • 提供比 ls 更详细的文件信息
