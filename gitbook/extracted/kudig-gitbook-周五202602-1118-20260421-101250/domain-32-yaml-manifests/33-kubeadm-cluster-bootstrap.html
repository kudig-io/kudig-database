# - 防火墙和 iptables 配置

总结

kubeadm 配置最佳实践

  1. 生产环境必须:

    • HA 控制平面（至少 3 节点）
    • 外部 etcd 或定期备份
    • 配置审计日志
    • 启用证书自动轮换
    • 使用 VIP/负载均衡器

  2. 安全加固:

    • 关闭匿名访问
    • 启用 RBAC
    • 配置 Pod Security Policy
    • 加密 Secret 数据
    • 定期更新证书

  3. 性能优化:

    • 调整 API Server 并发数
    • 配置 etcd 存储限额
    • 优化 Controller Manager 并发数
    • 配置合理的资源预留

  4. 监控运维:

    • 配置 Prometheus 监控
    • 收集审计日志
    • 定期备份 etcd
    • 制定证书续期流程
